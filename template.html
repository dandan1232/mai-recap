接上自己的那段回忆。

MCP 是让工具读取账号数据的一种连接方式。你可以直接在麦迹获取订单，也可以在支持 MCP 的 AI 助手里调用。

  1. 在官方平台申请凭证

    打开麦当劳官方 MCP 平台 ↗，使用手机号登录，进入“控制台”，按提示激活并同意服务协议，再复制 MCP Token。这个凭证代表你的账号，请自己保管。

  2. 回到麦迹，获取订单

    在“连接账号”里粘贴凭证，点击“获取我的订单”。查询完成会进入历史订单；再点击“翻开我的回顾”，就能阅读回顾和保存分享卡。

  3. 想在 AI 助手里调用？

    在支持 Streamable HTTP（可持续接收响应的网页连接方式）的 MCP 客户端中，添加服务地址 https://mcp.mcd.cn，并在认证设置中填入 Authorization: Bearer 你的凭证。不同客户端的字段名称可能不同，以各自说明为准。

    展开通用配置示例

    这是占位符示例。只在你自己的 MCP 客户端里替换 YOUR_MCP_TOKEN，不要把真实凭证发到聊天里。

    {
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}

    连接后，可使用下面这段话查询。调用的工具是 order-list，参数为 {}。

    请调用麦当劳 MCP 的 order-list 工具，参数使用 {}，查询我近期的到店与外送历史订单。整理每笔订单的下单时间、门店、餐品和状态，明确说明本次可查询范围。

    接入步骤与工具说明来自麦当劳官方 MCP 文档 ↗，核对日期：2026-10-20。

遇到这些情况时

凭证无效或过期：回到官方平台检查凭证，再重新查询。
查询太频繁：稍等一分钟，再试一次。
没有订单：保留空白结果，不会自动用示例代替。
只返回少量记录：接口提供近期订单，本页不能取得接口没有返回的更早记录。
